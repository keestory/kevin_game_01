# Phase 3 — Production QA & Polish

## 목표

프로토타입을 안정적인 제품 수준 수직 슬라이스로 다듬는다.

## QA

- 모든 뷰포트
- 화면 회전/리사이즈
- 백그라운드 탭 복귀
- 장시간 15분 soak test
- 파티클 풀 overflow
- 메모리 증가
- 입력 지연
- 접근성 설정 조합
- 오디오 mute/재개

## Polish

- 속성별 사운드 variation
- 콤보 단계별 믹스
- 보스 코어 파괴 L4 피드백
- 파워업 드롭 애니메이션
- 스테이지 시작/종료 전환
- 로딩과 오류 상태

## 제출물

- 실행 가능한 build
- 테스트 결과
- 성능 캡처
- 주요 해상도 스크린샷
- 남은 기술 부채 목록
