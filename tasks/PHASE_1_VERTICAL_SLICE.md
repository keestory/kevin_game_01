# Phase 1 — Playable Vertical Slice

## 목표

3분 동안 반복 플레이 가능한 1개 스테이지를 만든다.

## 포함

- 패들 이동
- 공 발사와 반사
- 6×10 벽돌 그리드
- 일반/강화/폭발/미스터리 벽돌
- 점수, 콤보, 생명
- Fire, Electric, Piercing, Multi Ball 드롭
- 일시정지와 재시작
- 게임오버와 클리어
- 기본 사운드 placeholder

## 스테이지 흐름

1. 1초 카운트다운
2. 공이 패들에 붙은 상태
3. 탭/Space로 발사
4. 콤보 상승과 파워업 드롭
5. 70% 파괴 시 속도 단계 상승
6. 전체 파괴 시 1.2초 결과 연출

## 완료 조건

- 고속 공 터널링 없음
- 공이 갇힐 경우 회복 로직 동작
- 공 8개 상태에서도 프레임과 점수 로직 안정
- 키보드/마우스/터치 모두 사용 가능
- 접근성 설정 유지
