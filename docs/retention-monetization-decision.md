# 1위 목표 유지율·수익화 판단

기준일: 2026-08-09

## 결론

사용자 가설을 그대로 전부 채택하지 않는다.

| 제안 | 판단 | 제품 결정 |
|---|---|---|
| 초반은 쉽고 중반부터 어렵게 | 채택 | 1~3역은 3종·안전 손잡이 3개, 6역부터 4종·손잡이 1개, 20역 이후 0개 가능 |
| 실패 후 광고로 목숨 획득 | 수정 채택 | 새 판은 항상 무료. 아까운 현재 판을 살리는 선택형 구조 광고만 판당 1회 |
| 친구가 설치·가입하면 목숨 지급 | 거부 | 설치·가입에는 보상하지 않고 동일 시드 도전을 실제 완료했을 때 비경쟁 꾸미기 보상 |
| 로그인 강제 | 거부 | 게스트 플레이를 기본으로 두고 Game Center는 선택 기능으로 제공 |

전역 목숨이 바닥나 플레이를 막으면 캐주얼 게임의 핵심인 `한 판 더`가 끊긴다. 광고 수익을 얻기 전에 사용자가 이탈할 가능성이 커지므로, 목숨은 계정 에너지가 아니라 한 판 안의 `안전 손잡이`로 바꿨다.

## 반영한 난이도 곡선

| 구간 | 제한 시간 | 목적지 | 안전 손잡이 | 설계 의도 |
|---|---:|---:|---:|---|
| 1~3역 | 32~38초 | 3종 | 3개 | 규칙 학습과 빠른 성공 |
| 4~5역 | 42~45초 | 3종 | 2개 | 처음으로 보드 위험 인지 |
| 6~10역 | 48~60초 | 4종 | 1개 | 첫 실제 실패와 구조 경험 |
| 11~19역 | 60초 | 4종 | 1개 | 목표 점수와 속도 상승 |
| 20역 이상 | 60초 | 4종 | 0~1개 | 숙련자 장기 도전 |

- 선택기 속도는 경계에서 갑자기 변하지 않고 smoothstep으로 상승한다.
- 같은 날짜·스테이지·rules에서 승객 순서는 플레이 속도와 무관하게 같다.
- 같은 스테이지를 2회 연속 실패하면 목표 점수 10% 감소, 선택기 10% 감속, 환승객 주기 단축을 적용한다.
- 이 보정은 몰래 적용하지 않고 홈과 HUD에서 `혼잡 완화 운행`으로 표시한다.

## 안전 손잡이와 구조 광고

열이 가득 찼을 때 손잡이가 남아 있으면 다음 순서로 복구한다.

1. 손잡이 1개 차감
2. 해당 열 상단 승객 3명 무점수 하차
3. 0.65초 입력 잠금
4. 선택기 3초간 25% 감속
5. 즉시 같은 판 재개

손잡이가 모두 소진되거나 제한 시간이 끝났을 때 판당 한 번만 구조를 제안한다.

- 생애 첫 구조: 광고 없이 무료
- 이후: 사용자가 선택한 보상형 광고의 reward callback이 확인된 경우만 구조
- 효과: 가장 높은 두 열에서 2명씩 무점수 하차, 제한 시간 15초 추가
- 거절: 손실 없이 결과 확인 후 즉시 새 판 시작
- 강제 전면광고: 출시 MVP에서 제외
- 광고를 쓴 기록: 구조 운행으로 표시하고 향후 공식 경쟁 순위에서 분리

2026년 레벨형 퍼즐게임의 대규모 현장실험은 획일적인 압박보다 플레이 상태에 맞춘 동적 난이도가 장기 보상형 광고 조회를 13.58%와 19.23% 높이면서 참여와 유지율도 개선했다고 보고했다. 이는 광고를 보기 위해 고의로 실패시키라는 뜻이 아니라, 단기 광고 조회와 장기 이탈을 함께 최적화해야 한다는 근거다. [Adaptive Design for In-App Advertising Games](https://papers.ssrn.com/sol3/Delivery.cfm/6137709.pdf?abstractid=6137709)

Apple은 광고 시청 같은 앱 내부 행동에 보상을 주는 것은 허용하지만, 광고는 명확히 표시되고 닫기·건너뛰기와 부적절한 광고 신고 수단을 제공해야 한다. 기능 이용을 위해 평가·리뷰·다른 앱 다운로드를 강요하거나 차트를 조작하는 행위는 허용하지 않는다. [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)

## 친구 설치 보상을 넣지 않는 이유

`친구가 설치하고 가입해야 내 목숨 지급`은 세 가지 문제가 있다.

1. 설치 후 게임을 좋아할 가능성보다 보상만 받는 저품질 설치가 늘어난다.
2. 공유 메시지가 초대가 아니라 스팸처럼 보이며 기존 이용자의 관계 비용이 커진다.
3. 앱 순위를 올리기 위한 인센티브 설치로 해석될 정책 위험이 있고, 로그인 기능이 핵심이 아닌 게임은 로그인 없이 사용할 수 있어야 한다.

대안은 `친구에게 같은 막차 보내기`다.

```text
결과 카드 공유
→ 친구가 동일 시드 도전 진입
→ 15초 튜토리얼
→ 공식 기록 1회
→ 두 기록 비교와 재대결
→ 실제 완료 시 양쪽에 같은 비성능형 스티커
```

Apple의 Game Center Challenges는 친구와 연락처를 점수형 라운드에 초대하고, 실시간 점수·알림·재대결을 제공한다. Games 앱과 App Store의 친구 발견 표면에도 연결되므로 자체 가입 추천 시스템보다 1차 출시 우선순위가 높다. [Game Center](https://developer.apple.com/game-center/), [Game Center Challenges](https://developer.apple.com/documentation/appstoreconnectapi/game-center-challenges)

설치 전 링크는 향후 Universal Link와 App Clip으로 연결한다. 링크를 열거나 설치한 사실에는 보상하지 않고, 실제 도전 완료 후에만 보상한다. [Universal Links](https://developer.apple.com/documentation/xcode/allowing-apps-and-websites-to-link-to-your-content/)

## 출시 확대 게이트

| 지표 | 중단선 | 확대 목표 |
|---|---:|---:|
| 1역 완료율 | 90% | 95% 이상 |
| 첫 판→두 번째 판 | 65% | 75% 이상 |
| 첫 세션 플레이 수 | 4판 | 6판 이상 |
| D1 유지율 | 30% | 35~40% |
| D7 유지율 | 8% | 12% 이상 |
| 구조 광고 선택률 | 15% | 20~30% |
| 광고 시청 후 다음 판 | 55% | 65% 이상 |
| 결과 공유율 | 3% | 5~8% |
| 스토어 전환율 | 25% | 35% 이상 |
| 크래시 없는 세션 | 99.5% | 99.7% 이상 |

D1 30% 또는 D7 8%를 넘지 못하면 1위 버스트 광고비를 확대하지 않는다. 먼저 첫 실패 시점, 구조 혜택, 1~5역 난이도와 광고 후 이탈을 수정한다.

## 구현 상태

- 스테이지별 목표·시간·목적지·안전 손잡이 곡선 구현
- 부드러운 시간 기반 선택기 가속 구현
- 2회 연속 실패 후 공개적 혼잡 완화 구현
- `playing → awaitingRescue → playing/finished` 상태 구현
- 첫 구조 무료와 중복 reward 방지 구현
- Debug/UI Test용 모의 보상 광고 구현
- Release용 광고 미연결 상태에서는 CTA를 숨기는 구현
- PlayerProfile v1→v2 점수·통계 보존 마이그레이션 구현
- 설치 보상 없이 시스템 공유 시트 기반 기록 공유 문구 구현

실제 출시 전 남은 일은 광고 SDK의 reward callback 연결, Game Center Challenges, Universal Link/App Clip, 서버 기반 도전 완료 검증, 분석 이벤트와 TestFlight 300~500명 실험이다.
