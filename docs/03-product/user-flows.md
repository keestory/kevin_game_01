# User Flows — 정위치! 만원열차

> 상태: DRAFT / Product Spec revision 1 종속
> Source of Truth: `docs/product-specs/real-train-braking.product-spec.md`

## 1. 정보 구조

```text
앱 실행
└─ 홈
   ├─ 운행 시작
   │  └─ 실제 열차 게임
   │     ├─ 첫 결과까지 비차단 coachmark
   │     ├─ 역 접근 → 지금 제동 → 정차 판정
   │     ├─ 문 개방 → 실제 승하차 → 다음 역
   │     ├─ 일시정지
   │     ├─ 조건부 추가 역 제안
   │     └─ 결과
   │        ├─ 같은 운행 다시
   │        ├─ 운행 기록 공유
   │        └─ 홈
   └─ 설정
```

계정, 알림 동의, 친구 설치, 결제, 실제 광고 SDK는 현재 흐름에 없다.

## 2. 첫 실행

```text
홈 → 60초 운행 시작
→ 첫 프레임부터 실제 측면 열차와 플랫폼 노출
→ “노란 구간에서 ‘지금 제동’을 누르세요” coachmark
→ 제동 가능 구간 전에는 60초 유지
→ CTA “역 접근 중” → “지금 제동”
→ 첫 perfect/safe/near/miss 결과
→ coachmark 종료
```

- 튜토리얼은 모달이 아니며 제동을 막지 않는다.
- 기존 v1/v2 프로필도 v3 마이그레이션에서 새 제동 안내를 다시 본다.
- 백그라운드 진입 시 즉시 일시정지하고 자동 재개하지 않는다.

## 3. 코어 운행

```text
플랫폼·정차선 접근
→ 한 번 탭해 제동
→ timing error로 perfect/safe/near/miss 계산
→ 성공 정차: 세 쌍의 문 개방 + 승객 하차/탑승
→ 등급·하차 인원·사운드·햅틱
→ 문 닫힘 + 다음 역 출발
→ 기본 5개 역 종료
```

정위치 시 최대 하차 인원은 `[5, 6, 6, 7, 8]`이며 1단계 목표는 총 32명 중 22명이다. 동일 시드·제동 시각은 동일 결과를 만든다.

## 4. 실패·추가 역·무료 재시도

```text
5개 역 후 목표 미달
→ 남은 목표가 8명 이하이고 추가 역 미사용?
   ├─ 예: 추가 역 제안
   │  ├─ 첫 무료 연장 → 다음 역 1회·+12초
   │  ├─ 검증 후 광고 후보 → reward callback 확인 시만 지급
   │  └─ 무료로 같은 운행 다시 → 즉시 새 운행
   └─ 아니오: 결과
      └─ 같은 운행 다시 → 즉시 새 운행
```

- 첫 세 운행에는 광고 CTA를 노출하지 않는다.
- 무료 재시도가 기본이며 광고 거절·로드 실패가 막지 않는다.
- `다음 역 +12초`는 현재 prototype 가설이고, 실제 광고 후보는 `마지막 제동 1회 되돌리기`와 별도 A/B 전까지 확정하지 않는다.
- 동일 impression은 한 번만 처리하고 이전 런 callback은 무시한다.

## 5. 결과·공유

```text
결과
├─ 무료 재도전
├─ 시스템 ShareLink로 기록 텍스트 공유
└─ 홈
```

설치·가입·평점·연락처 제공은 보상 조건이 아니다. 현재 공유에는 딥링크와 양방향 보상이 없다.

## 6. 일시정지·수명주기

- 사용자 일시정지: `계속 운행`, `오늘은 여기까지` 제공.
- 전화·제어 센터·백그라운드: 시간·입력·오디오를 멈춘다.
- active 복귀: 자동 재개하지 않고 사용자가 선택한다.
- 이전 Scene 이벤트와 늦은 광고 callback은 현재 런을 변경하지 않는다.

## 7. 접근성

- CTA는 최소 64pt이며 시각·VoiceOver 모두 `역 접근 중/지금 제동/승하차 중` 상태를 전달한다.
- 정차 등급·하차 인원은 텍스트와 접근성 값으로 전달한다.
- 색 외에 흰 정차선·텍스트·승객 도형 배지를 제공한다.
- Reduce Motion은 비필수 배경 스크롤·진동·흔들림·파티클을 제거한다.
- 사운드와 햅틱은 독립적으로 끌 수 있다.

## 8. Flow Gate

자동 테스트와 소스 감사만으로 사용자 흐름을 승인하지 않는다. 서로 다른 신규 사용자 패널로 2초 열차 인지 5/5, 5초 목표 이해 4/5, 3회 플레이의 자발적 두 번째 운행 4/5와 재미 중앙값 4/7을 통과해야 한다.
