# Return Shot 사용성 테스트 계획

> 상태: **NOT RUN — 결과 없음**
>
> 현재 단계: Stage 6 Implementation. 코드·XCUITest·Vision 캡처는 실제 재미와 학습을 대체하지 않는다.

## 연구 질문

1. 설명 없이 5초 안에 패들을 움직여 첫 공을 리턴하는가.
2. 접촉 위치와 패들 속도로 다음 각도를 바꾼다고 이해하는가.
3. 색·무늬·마크 LINK, 프리즘 3HP, 마이너스 간접 제거를 첫 60초 뒤 설명하는가.
4. 같은 seed에서 세 번째 run 기록이 첫 run보다 상승하는가.
5. 실패 원인을 자기 조작으로 설명하고 자발적으로 재도전하는가.
6. A가 B보다 판단하기 쉽고 공·위험·지지 관계를 덜 가리는가.
7. VoiceOver·Dynamic Type·Reduce Motion에서 핵심 흐름이 가능한가.

## 참여자

최소 5명: 한국 iPhone casual 사용자 3명, 색각/큰 글자 사용 경험 1명, VoiceOver·Voice/Switch Control 실제 사용자 1명. A/B 방향성은 8~15명으로 확장한다.

## 과업과 사전 기준

| ID | 과업 | 통과 기준 |
|---|---|---|
| RS-T01 | coachmark 없이 첫 run 시작 | 4/5가 5초 내 첫 리턴 |
| RS-T02 | 30초 자유 플레이 | active-touch 중앙값 ≥60%, 의미 있는 steering 20~40회/분 |
| RS-T03 | 첫 60초 뒤 규칙 설명 | 4/5가 LINK·프리즘·마이너스 제거 설명 |
| RS-T04 | 같은 seed 3회 | 3/5 자발적 3회차, Run 3 중앙값 ≥ Run 1 ×1.20 |
| RS-T05 | 첫 miss 뒤 원인 설명 | 4/5가 자기 조작으로 설명, 공 관통·불공정 0 |
| RS-T06 | A/B 동일 seed 비교 | A가 판단 용이성에서 우세, B의 연결선 가림 보고 없음 |
| RS-T07 | 접근성 설정별 흐름 | 시작→조작→일시정지→결과→재도전 완료 |

재미는 7점 척도 중앙값 4 이상을 최소선으로 둔다. 표본 5명의 비율을 시장 전체에 일반화하지 않는다.

## Stop 조건

- 4/5 미만이 5초 안에 첫 리턴
- 3/5 미만이 자발적 세 번째 run
- Run 3 기록 상승 중앙값 20% 미만
- 2/5 이상이 `그냥 벽돌깨기`라고만 설명하거나 LINK·간접 제거를 이해하지 못함
