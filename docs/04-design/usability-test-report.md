# Usability Test Report — 실제 열차 프로토타입 계획

> 상태: **NOT RUN — 결과 없음**
> 현재 단계: Stage 4 Solution Definition 재작업
> 코드·XCUITest·스크린샷은 사용자 연구를 대체하지 않는다.

## 연구 질문

1. 텍스트 없이 2초만 봐도 실제 지하철로 인지하는가.
2. 5초 뒤 `정차선에 맞춰 제동해 승객을 내린다`고 설명하는가.
3. 첫 제동 시점과 판정이 공정하다고 느끼는가.
4. 문 개방과 실제 승하차가 만족스럽고 두 번째 운행을 유발하는가.
5. 움직이는 배경이 멀미·혼란·오탭을 높이지 않는가.
6. 무료 재시도와 선택형 추가 역의 비용·보상을 정확히 이해하는가.
7. Reduce Motion·Voice Control·Switch Control에서 핵심 과업이 가능한가.

## 참여자

최소 5명:

- 모바일 퍼즐/캐주얼 주 3회 이상 2명
- 캐주얼 월 1~4회 1명
- Larger Text 또는 색각 보정 경험 1명
- VoiceOver·Voice Control·Switch Control 실제 사용자 1명

방향성 추가 실험은 한국 iPhone 사용자 10명으로 이동형 B와 정지형 A를 비교한다.

## 과업과 사전 기준

| ID | 과업 | 통과 |
|---|---|---|
| T01 | 텍스트 가린 게임 화면 2초 노출 후 무엇인지 설명 | 5/5 열차·지하철 |
| T02 | 5초 자유 관찰 후 목표 설명 | 4/5 정차선·제동·하차 언급 |

| T06 | 실패·추가 역 제안 | 5/5가 무료 재시도·광고 여부·+12초를 정확히 이해 |
| T07 | Reduce Motion 플레이 | 멀미 0, 핵심 상태 식별 5/5 |

재미는 7점 척도 중앙값 4 이상을 최소선으로 둔다. 표본 5명의 퍼센트를 시장 전체로 일반화하지 않는다.

## 이동형 A/B 중단 기준

- 이동형의 오탭이 정지형보다 상대 20% 이상 높음
- 이동형 첫 승리 시간이 15% 이상 느림
- 10명 중 2명 이상 멀미·시각 혼란 보고
- 셀당 최소 100명의 방향성 테스트에서 3회차 재플레이 또는 D1 개선 없음
- 스토어 전환만 상승하고 D1이 하락

하나라도 충족하면 패럴랙스를 축소하거나 이동 콘셉트를 중단한다.
