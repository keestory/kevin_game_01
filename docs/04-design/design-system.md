# Draft Design System — 정위치! 만원열차

> 상태: DRAFT / Stage 4 vertical slice

## 원칙

1. **열차가 규칙이다:** 차체·문·바퀴·선로·플랫폼과 승객 동선이 점수의 원인과 결과를 설명한다.
2. **한 번의 명확한 입력:** 하단 제동 CTA 하나에 시각 위계를 집중한다.
3. **색 외의 의미:** 정차선·아이콘·텍스트 등급·숫자를 색과 함께 사용한다.
4. **모션은 목적과 선택:** 주행과 감속을 설명하되 Reduce Motion에서 제거한다.
5. **실패는 정보:** `역을 통과했어요`, `6명이 더 기다리고 있어요`처럼 원인과 다음 무료 행동을 말한다.
6. **실제 기관과 분리:** 허구 역명과 독자 차체, 런타임 합성음을 사용한다.

## 핵심 컴포넌트

### 실제 열차

- 논리 화면 390×844pt에서 약 366×226pt.
- 창문 4개, 미닫이문 3쌍, 바퀴 2개, 노선 표시기, 노란 차체 띠, 전조등.
- 승객은 28~34pt 사람 형태이며 몸에 목적지 도형을 표시한다.
- 문 패널은 0.24초 좌우 이동하고, 승객은 문을 통과하는 경로를 가진다.

### 제동 CTA

- 화면 좌우 20pt, 높이 64pt, 둥근 22pt 모서리.
- 정차 접근 전에는 낮은 대비, 입력 가능 시 safetyYellow와 `제동` 텍스트.
- 상단 진행 바에는 넓은 노란 구간, 좁은 민트 정위치, 흰 정차선을 동시에 표시한다.
- Voice Control·Switch Control용 실제 SwiftUI Button이다.

### HUD

- 좌: `하차 0/22명`; 중앙: 남은 시간; 우: `1/5역`과 pause.
- 점수는 결과 보조 정보이며 하차 목표보다 위계가 낮다.
- 역 접근 배너는 가상 역명과 하차 예정 인원을 한 줄로 표시한다.

## 모션·사운드·햅틱

| 사건 | 기본 | Reduce Motion |
|---|---|---|
| 주행 | 먼 도시 0.35×, 기둥 1×, 선로 1.6× | 정적 배경 |
| 객차 | 1~2pt 저진폭 진동 | 고정 |
| 제동 | 0.56초 감속·최대 10pt 정렬 | 진행 바와 fade |
| 정위치 | 차표 파티클 20개, 성공 햅틱·화음 | 텍스트·문 조명만 |
| 통과 | 3pt 흔들림, 불꽃 8개, warning | 흔들림·불꽃 제거 |
| 문 | 0.24초 개폐, 코드 합성 차임 | 동일한 짧은 개폐 또는 즉시 상태 |

사운드는 AVAudioEngine 사인파 합성으로 생성하며 실제 철도 녹음을 쓰지 않는다. 사운드·햅틱은 각각 설정에서 끌 수 있다.

## 문구

- 홈: `정차선에 맞춰 승객을 내려요`
- 시작: `60초 운행 시작`
- 튜토리얼: `노란 구간에 들어오면 제동`
- 등급: `정위치!`, `안전 정차`, `조금 어긋났어요`, `역을 통과했어요`
- 재시도: `같은 운행 다시`
- 공유: `운행 기록 공유하기`
- 금지: 실제 노선명, 죄책감 문구, 허위 카운트다운, 광고 거절을 숨기는 표현

## Gate

현재 **Revise**다. 2초 열차 인지 5/5, 5초 목표 이해 4/5, 최대 Larger Text, 보조기술, 대비, 멀미 테스트 전 확정 시스템으로 간주하지 않는다.
