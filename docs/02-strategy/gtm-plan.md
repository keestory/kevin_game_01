# GTM Plan — 검증 후 집중 출시

## 전략 원칙

무료 Games 1위는 다운로드 결과이지 스토어 메시지가 아니다. Apple의 순위 산식·필요 다운로드·유료 비중은 공개되지 않았다. 먼저 반복 플레이와 단위경제를 만들고, 출시 순간에는 짧은 크리에이티브·사전주문·스토어 전환·커뮤니티 챌린지를 같은 48시간에 집중한다.

## 채널 우선순위

| 채널 | 근거 | 첫 실험 | 성공 지표 |
|---|---|---|---|
| 숏폼 gameplay/review | 인디 발견 41.0% [E11] | 실제 5초 루프 3소재 | hold, CTR, install, D1을 소재별 연결 |
| 지인·커뮤니티 공유 | 지인추천 33.3% [E11] | 동일 시드 결과 카드 | share→open→install→first game |
| App Store 검색·PPO | 순위 발견 34.0% [E11], PPO 공식 도구 [E22] | 아이콘/스크린샷 최대 3안 | product-page CVR와 신뢰구간 |
| Apple Ads | 키워드 도구 제공 [E24] | exact 중심 소액 탐색 | CPI와 D7/LTV, 설치량만 보지 않음 |
| 사전주문·피처링 신청 | 2~180일 pre-order, 피처링 3주 전 권고 [E21, E23] | 검증된 빌드·스토리 제출 | preorder→install→D1; 피처링은 0으로 계획 |

## 단계별 실행

### A. Stage 2: 2026-08-10~08-23

- 인터뷰 12명, 일기 8명, 사용성 5명
- 브랜드 없는 교통/중립/캐릭터 소재 비교
- `1분`, `공정`, `같은 판` 중 실제 선택을 만드는 메시지 확인
- 실패 기준 충족 시 테마·문제·루프를 수정하고 출시 일정을 잡지 않는다.

### B. 제한 베타

- TestFlight 150~300명을 소스별 cohort로 모집
- 코어 지표 통과 전 광고·referral을 성장 엔진으로 해석하지 않음
- 광고 0/1회, 난이도 곡선 2안, 공유 카드 2안을 각각 분리 시험
- 버그·광고 크리에이티브·결제 복구 SLA를 운영 리허설

### C. 소프트런치와 스토어 준비

- 소액 Apple Ads로 실제 CPI와 유지율을 연결
- PPO로 실제 화면·영상만 비교; 최대 3 treatment, 최대 90일 [E22]
- 신규 앱 사전주문은 2~180일 범위에서 설정 가능 [E21]
- 피처링 nomination은 최소 3주 전 제출하되 획득을 전제로 예산을 세우지 않음 [E23]
- 키워드 가설: `퍼즐 게임`, `두뇌 게임`, `한손 게임`, `교통 정리`; 검색량·경쟁도 확인 후 수정

### D. 검증된 경우의 출시 48시간

- 같은 시각에 크리에이터 챌린지, 커뮤니티 오늘의 시드, 사전주문 알림, 검색광고를 집중
- 2~4시간 단위로 install source, 스토어 CVR, CPI, first game, crash, 광고 오류를 본다.
- 차트 순위는 결과 지표로 기록하되 유지율 저하를 감수해 설치만 사지 않는다.

## 크리에이티브 가설

1. “이 한 칸, 어디로 옮길래?” — 실제 보드 5초
2. “오늘 친구와 같은 열차” — 같은 시드 결과 비교
3. “실패해도 이유가 보이는 1분 퍼즐” — 공정성

광고 소재와 실제 플레이를 일치시키며 경쟁작/IP 이름을 메타데이터에 부당하게 사용하지 않는다. [E06, E19](../01-research/evidence-register.md)

## Stop / Scale 규칙

- 인터뷰·일기·사용성 반증 기준 미달: **Stop acquisition, Revise product**
- D1/D7/재도전 내부 기준 미달: 유료 UA와 사전주문 확대 중단
- 광고군의 유지 손실이 사전 한도 초과: 빈도·위치 변경 또는 광고 모델 중단
- `CPI > D90 contribution LTV × 0.5`: 해당 채널 scale 중단
- 크리에이티브가 클릭만 높고 D1이 낮음: 미스리딩으로 판정하고 폐기
- 부적절 광고·결제 유실·crash 급증: 캠페인 즉시 중지, 복구 후 재검증

## 알려지지 않은 것

한국 iPhone 무료 Games #1 임계 다운로드, 현재 퍼즐 CPI, 본 게임의 오가닉 증폭·공유 K-factor, Apple 피처링 가능성, 적정 출시일과 승인 예산은 모두 미정이다.
