## 우선순위

1. H1 문제·맥락과 H3 코어 루프를 사용자 행동으로 먼저 반증한다.
2. H2 소재를 코어 재미와 분리해 검증한다.
3. H5·H10은 실제 유지율과 광고 노출량 없이는 숫자를 만들지 않는다.
4. H7은 가장 위험하다. **현재 근거로 1위 계획을 승인하지 않는다.**

## 정책상 폐기하는 가정

- “친구가 설치·가입하면 생명 지급”은 바이럴 실험 기본안에서 제외한다. 스팸·사기·어뷰징과 추적 부담이 크고, 다른 앱 다운로드나 스토어 행동을 기능 접근 조건으로 삼는 설계는 Apple 3.2.2(x) 취지와 충돌할 여지가 있다. 대신 설치 보상 없는 동일 시드 링크와 결과 카드만 시험한다. [E19](../01-research/evidence-register.md)
- “평점 5점이면 생명 지급”, “리뷰 작성 시 재화”는 사용하지 않는다. 스토어 발견·평점 조작 위험이다. [E19](../01-research/evidence-register.md)
