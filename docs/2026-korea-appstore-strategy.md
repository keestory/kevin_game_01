# 2026 한국 App Store 게임 전략

기준일: 2026-08-09, 시장: 대한민국 iPhone 무료 게임 차트

## 한 줄 결론

대규모 IP 방치형 RPG와 정면 승부하지 않는다. 설명 없이 바로 이해되는 퍼즐에 한국적인 만원열차 소재, 60초 경쟁, 일일 동일 시드와 공유 결과를 결합한 `한 칸만! 만원열차`로 무료 차트 다운로드 집중을 노린다.

앱 이름은 `한 칸만! 만원열차`, 부제는 `퇴근길 60초 원터치 퍼즐`이다.

## 시장 스냅샷

Apple 공식 한국 iPhone 차트를 2026년 8월 9일 KST에 재확인했을 때 `여전사 키우기`와 `쿠키런 키우기`가 무료 게임 상위 2개 자리를 차지했고, `퍼즐 오브 Z`, `블라이트 워: 방치형 RPG`, `티니핑 매직 매치`도 상위권에서 관측됐다. 같은 날 확인 시점에 따라 상위 2개의 순서가 달랐으며 Apple의 과거 시점 스냅샷을 보관하지 않았으므로, 이 문서에서는 정확한 일중 순위를 고정 사실로 사용하지 않는다. 이는 2026-08-09의 변동 가능한 관측값이며 다운로드 수 공개 자료가 아니다.

상위권과 상위 25위에는 색상 정렬, 컬러링, 블록, 머지, 매치3, 교통 정리처럼 한눈에 규칙을 이해할 수 있는 퍼즐이 반복해서 나타났다. 이 장르 분포에서 소규모 팀의 진입 가능성을 읽은 부분은 내부 추론이다.

이 차트는 다음 두 가지를 동시에 보여준다.

- IP와 UA 자본이 강한 키우기·방치형 신작은 출시 버스트에 유리하다.
- 소규모 팀도 낮은 설명 비용과 짧은 세션을 가진 퍼즐로 다운로드 경쟁에 진입할 수 있다.

한국 모바일게임 매출은 RPG·미드코어 비중이 여전히 크지만, Sensor Tower의 한국 시장 보고서는 하이브리드 캐주얼과 머지 장르의 성장을 함께 지적한다. 다운로드 1위와 매출 1위는 다른 문제이므로 이번 MVP는 먼저 `무료 게임 차트 1위 가능성`과 코어 유지율을 검증한다.

## 왜 이 게임인가

후보는 `한 칸만! 만원열차`, 떡볶이 물리 스택, 직장인 타이밍 게임, 비동기 랜덤 협동 전략이었다. 최종안은 아래 기준으로 선정했다.

| 기준 | 만원열차 | 물리 스택 | 직장인 타이밍 | 랜덤 협동 |
|---|---:|---:|---:|---:|
| 첫 3초 이해 | 높음 | 높음 | 높음 | 중간 |
| 한국 소재 차별성 | 높음 | 중간 | 높음 | 높음 |
| MVP 구현·QA 비용 | 낮음 | 중간 | 낮음 | 높음 |
| 60초 반복성 | 높음 | 중간 | 중간 | 높음 |
| 서버 없이 검증 | 가능 | 가능 | 가능 | 어려움 |
| 숏폼·결과 공유 | 높음 | 중간 | 높음 | 높음 |

랜덤 협동은 장기 확장성이 더 크지만 서버와 라이브 밸런스 없이 검증하기 어렵다. 만원열차는 로컬 퍼즐만으로 `아이콘 → 설치 → 첫 재미 → 재도전 → 공유` 퍼널을 가장 빨리 측정할 수 있다. 초기 지표가 나오면 비동기 친구 도전을 2단계로 추가한다.

## 코어 제품

- 보드: 5열 × 7행
- 조작: 움직이는 문이 원하는 열에 왔을 때 화면 아무 곳이나 탭
- 규칙: 같은 목적지 배지 3명 이상이 상하좌우로 연결되면 하차
- 구분: 색뿐 아니라 원·세모·별·네모 모양을 함께 사용
- 와일드카드: 9번째마다 모든 목적지와 이어지는 환승객
- 세션: 60초, 한 열이 넘치면 조기 종료
- 변화: 15초마다 선택기 속도 상승과 역 보너스, 20초 뒤 목적지 4종
- 경쟁: 날짜 기반 동일 시드, 최고 점수와 결과 공유

비주얼은 가상 한국 지하철 안내 체계와 둥근 스티커 캐릭터를 결합한다. 실제 교통기관 로고, 노선 번호, 노선도는 복제하지 않는다.

## 성장과 수익화

MVP에는 강제 광고와 확률형 상품을 넣지 않는다. D1과 재도전율을 먼저 검증한 뒤 다음 순서로 확장한다.

1. Game Center 일일·주간 순위와 친구 점수 도전
2. 결과 카드 이미지와 마지막 연쇄 6초 리플레이
3. 열차·창밖 풍경·승객 스킨 같은 비성능형 수집
4. 선택형 보상 광고: 조기 종료 1회 구조, 보상 2배
5. 광고 제거권과 꾸미기 시즌 패스

광고 보상이 명확해야 참여한다는 국내 조사 결과를 반영해, 보상형 광고는 가치와 선택권을 먼저 보여준다. 순위 경쟁력이나 퍼즐 정답을 직접 판매하지 않는다.

## 출시 퍼널

### D-45~D-15: 검증

- 30명 대면 테스트에서 첫 판 무설명 성공 여부 관찰
- TestFlight 300명으로 튜토리얼, 난이도, 오류 이벤트 수집
- 아이콘 3안과 첫 스크린샷 3안을 소규모 광고로 사전 테스트
- 크리에이터 20명에게 동일한 `오늘의 막차` 시드 제공
- Apple 피처링 후보 제출과 사전예약 페이지 준비

### D-14~D-1: 집중

- 6초·10초·15초 영상 소재를 실패, 대연쇄, 친구 도전 세 갈래로 운영
- 카카오톡 공유 카드, YouTube Shorts, Instagram Reels 비율에 맞춘 결과물 제작
- 출시 첫 주 도전 시드와 라이브 밸런스 핫픽스 준비
- App Store 제품 페이지 아이콘·스크린샷·영상 조합 테스트 설정

### 출시 48시간

- 사전예약 자동 다운로드, Apple Ads, 크리에이터 게시를 같은 시간대로 집중
- 결제보다 `첫 판 완료 → 즉시 재도전 → 결과 공유`를 최우선 노출
- 크래시, 튜토리얼 이탈, 광고별 설치 후 첫 판 완료를 실시간 관찰
- 부정 리뷰를 숨기지 않고 재현 가능한 버그와 밸런스 문제를 빠르게 분리

## 지표와 중단 기준

아래 값은 시장 평균을 그대로 옮긴 수치가 아니라, 유료 확장 전에 요구할 내부 제품 게이트다.

| 지표 | 최소 게이트 | 목표 |
|---|---:|---:|
| 스토어 페이지 전환율 | 25% | 30~35% |
| 첫 판 시작률 | 80% | 90% |
| 튜토리얼/첫 판 완료율 | 70% | 80% |
| 첫 세션 재도전율 | 40% | 55% |
| D1 유지율 | 30% | 35% |
| D7 유지율 | 10% | 12% 이상 |
| 결과 공유율 | 3% | 7% |
| 크래시 없는 세션 | 99.5% | 99.8% |

D1 30% 또는 첫 세션 재도전 40%를 넘지 못하면 UA를 확대하지 않는다. 광고 소재보다 코어 규칙, 속도, 튜토리얼을 먼저 수정한다. 오가닉이 유료 설치를 추월하기 시작하고 목표 지표를 2개 코호트 연속 통과할 때만 1위 버스트 예산을 확장한다.

## 사업개발 판단

- 목표 시장: 첫 출시는 한국 iOS, 제품 검증 직후 Android 동시 준비
- IP: 실제 지하철 기관 대신 자체 캐릭터와 가상 노선으로 글로벌 현지화 가능성 확보
- 파트너 우선순위: 한국 숏폼 크리에이터 → 통근·직장 라이프스타일 브랜드 → 캐릭터 굿즈/IP 파트너
- 협업 상품: 브랜드 로고를 보드에 넣기보다 기간 한정 승객·가방·창밖 배경으로 분리
- 예산은 정액으로 먼저 확정하지 않고, 소재별 `설치 → 첫 판 완료 → D1` 비용으로 단계 해제

App Store 1위는 보장 가능한 개발 산출물이 아니다. 합법적인 사전예약, 실제 이용자 만족, 크리에이터 노출과 광고 집중으로 시도해야 하며 설치 보상·허위 리뷰·차트 조작은 사용하지 않는다.

## 에이전트별 산출물 반영

- 전략·사업개발·마케팅: 차트/매출 구조, 하이브리드 캐주얼 틈새, 사전예약과 48시간 런칭, KPI 게이트
- 기획·UI/UX: 60초 원터치 규칙, 5×7 보드, 일일 시드, 가상 지하철 디자인, 접근성
- 엔지니어링·QA: SwiftUI/SpriteKit 분리, 순수 규칙 엔진, Swift 6 MainActor, 라이프사이클 정지, 유닛/UI 테스트와 성능 게이트
- 이미지 제작: 텍스트와 실제 교통 로고가 없는 노란 문·민트 승객 앱 아이콘
