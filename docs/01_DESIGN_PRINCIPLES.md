# 01. Design Principles

## 1. 한 문장 정의

**공 하나의 궤적이 화면 전체의 에너지를 지휘하는, 읽기 쉬운 고밀도 네온 액션.**

## 2. 핵심 원칙

### 2.1 Impact First

충돌은 게임의 가장 작은 보상 단위다. 모든 충돌은 소리, 형태 변화, 빛, 파편, 점수 중 최소 3개 채널로 피드백한다.

### 2.2 Readable Chaos

화면이 화려해질수록 정보 계층을 더 엄격하게 유지한다. 플레이어는 100ms 안에 아래를 파악할 수 있어야 한다.

- 내 공이 어디에 있는가
- 공이 어느 방향으로 이동하는가
- 어떤 속성이 활성화되어 있는가
- 다음 위험은 무엇인가
- 내가 잘하고 있는가

### 2.3 Element Has Behavior

불은 주황색 공이 아니라 잔열과 지속 피해다. 전기는 파란색 공이 아니라 빠른 분기와 연쇄다. 각 속성은 색, 실루엣, 시간 리듬, 사운드, 게임 규칙이 함께 달라야 한다.

### 2.4 Escalation

콤보가 올라가면 단순히 숫자만 커지지 않는다.

- 0–9: 안정적인 기본 상태
- 10–19: 트레일과 사운드 레이어 증가
- 20–49: 임팩트 크기와 배경 반응 증가
- 50+: 과부하 직전의 Frenzy 상태, 단 가독성 상한 유지

### 2.5 Controlled Glow

글로우는 정보 중요도를 표현한다. 모든 요소가 빛나면 아무것도 중요하지 않다.

- 공 코어: 항상 강함
- 충돌점: 순간적으로 매우 강함
- 활성 스킬 아이콘: 중간
- 패널 테두리: 약함
- 비활성 UI: 거의 없음

## 3. 시각적 성격

| 축 | 지향점 | 피해야 할 것 |
|---|---|---|
| 분위기 | 어두운 우주선/아케이드 경기장 | 밝은 캐주얼 퍼즐 느낌 |
| 형태 | 날카로운 모서리 + 제한적 라운드 | 모든 요소의 과도한 캡슐화 |
| 빛 | 중심 코어와 방향성 있는 글로우 | 화면 전체 블룸 |
| 타이포 | 압축된 헤드라인 + 읽기 쉬운 본문 | 장식체 남용 |
| 모션 | 짧고 강한 반응 | 느린 UI 애니메이션 |
| 효과 | 속성별 고유 문법 | 색상만 다른 동일 파티클 |

## 4. 게임 화면 정보 계층

1. 공과 예상 궤적
2. 패들과 즉시 위험
3. 타격 대상 벽돌
4. 보스/특수 패턴
5. 활성 파워업 및 남은 시간
6. 점수와 콤보
7. 배경 장식

## 5. 세계관 확장 방향

같은 디자인 시스템으로 아래 테마를 확장할 수 있다.

- Space: 행성, 성운, 에너지 코어
- Neon City: 전광판, 비, 사이버 도로
- Jungle Ruin: 생체 발광, 고대 룬
- Machine Core: 금속, 오일, 경고등
- Abyss Ocean: 심해 입자, 압력 파동

테마가 바뀌어도 공, 충돌점, 속성 컬러의 대비는 유지한다.
