# User Research Plan — 실제 인터뷰 0건

## 현재 증거 상태

**2026-08-09 현재 이 제품에 대한 실제 사용자 인터뷰, 관찰 테스트, 일기 연구는 수행되지 않았다.** 아래 인사이트는 KOCCA 설문과 스토어 리뷰를 이용한 데스크 리서치이며, 질문 응답이나 실제 행동으로 검증되지 않았다.

### 데스크 리서치 신호

- `사실` 모바일 이용자 조사에서 퍼즐·퀴즈 선호와 인디 이용자의 가벼운 콘셉트·간단 조작 선호가 관측됐다. [E12, E13](evidence-register.md)
- `사실` 인디게임 발견은 영상, 스토어 순위, 지인 추천, 광고로 분산돼 있었다. [E11](evidence-register.md)
- `사실` 최근 경쟁 리뷰에는 강제 광고, 불공정성, 버그·결제 신뢰 문제가 있었다. [E03–E09](evidence-register.md)
- `미확인` 위 집단이 한국 iPhone 통근자와 얼마나 겹치는지, 만원열차 소재를 반기는지, 실제로 재도전하는지는 알 수 없다.

## Stage 2 최소 연구

### 1. 문제 인터뷰 12명

- 한국 거주 iPhone 사용자
- 20대 4명, 30대 4명, 40~50대 4명; 성별 균형
- 현재 짧은 퍼즐 이용자 4명, 최근 중단 4명, 비이용/거부 가능성이 큰 anti-segment 4명
- 지인·팀 내부만으로 모집하지 않고 응답 유도 금지

질문은 콘셉트를 보여주기 전에 최근 실제 행동부터 묻는다.

1. 지난 7일 동안 이동·대기 중 휴대폰으로 무엇을 했는가?
2. 가장 최근 짧은 게임을 켠 구체적 순간과 그 직전 행동은 무엇인가?
3. 무엇 때문에 그만두거나 삭제했는가? 마지막 상황을 보여줄 수 있는가?
4. 광고를 보고 계속한 최근 사례와 즉시 종료한 사례는 무엇이 달랐는가?
5. 친구에게 게임을 공유한 마지막 사례에서 무엇을, 왜 보냈는가?
6. 현재 대체재가 충분하다면 왜 새 앱을 설치하지 않을 것인가?

### 2. 5일 일기 연구 8명

- 실제 micro-break의 시각, 장소, 가용 시간, 선택한 대체재, 종료 이유를 기록
- 게임을 하라고 요구하지 않는다.
- 성공 신호: 8명 중 4명 이상이 5일 중 3일 이상 동일한 반복 맥락을 자연스럽게 기록

### 3. 블라인드 소재 선택 실험

- 교통, 중립 블록, 캐릭터 등 브랜드 없는 3개 크리에이티브
- 동일 규칙·카피·노출로 비교; 가능하면 안당 1,000 impressions 이상
- CTR만으로 수요를 확정하지 않고 랜딩→대기명단/설치 의향 행동까지 본다.
- 실패: 교통 소재가 대조군 대비 상대적 lift가 없으면 테마를 수정하고 코어 문제와 분리한다.

### 4. 조작 관찰 5명

- 설명 없이 첫 판, think-aloud는 첫 행동 후 시작
- 성공: 4/5가 도움 없이 첫 판 완료, 3/5가 요청 없이 재도전
- 실패 원인을 “내 선택”으로 설명하는지와 광고 제안의 정서 반응을 기록

### 5. 지불 행동

“살 의향이 있나요?” 대신 실제 선택을 본다. 광고 보기/기다리기/게임 종료, 광고 제거·외형 아이템 대기명단 또는 작은 실제 결제 실험을 법·스토어 범위 내에서 사용한다.

## 반증·중단 기준

- 12명 중 6명 미만이 유도 없이 반복 문제와 현재 대체재를 구체적으로 말하면 문제 정의 수정
- 일기 8명 중 4명 미만이 3일 이상 맥락을 기록하면 “통근 micro-break” 세그먼트 수정
- 사용성 기준 미달이면 마케팅·수익화 전에 코어 루프 수정
- 교통 소재가 중립 대조군보다 낫지 않으면 테마를 핵심 차별점에서 제거
- 친구 설치 보상 없이 공유할 이유를 12명 중 3명도 제시하지 못하면 referral을 핵심 성장 엔진에서 제외

## 기록 양식

각 관측은 참여자 ID, 모집 조건, 실제 발화/행동, 해석, 반대 증거, 신뢰도, 후속 실험을 분리한다. 개인식별정보는 최소화하고 동의 없이 화면·음성을 저장하지 않는다.
